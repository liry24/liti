## Phase 1 design decisions

| Gate                                         | Decision and installed-distribution evidence                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Validation across Console / Agent / Schedule | Use public Workspace `write:validate` hooks for every mutation and an explicit authorized server operation scope for managed models. The fixture rejects direct Content, Console RPC, inline Agent, generic scheduled publish, remove and restore outside that scope. The email-prefix policy is synthetic test authorization, not the production role policy. Production Model operations must validate current model rules and authorization again.                                                                                                                                                                                                         |
| Immutable scheduled publication              | Native Content schedule intentionally fails after draft edits. A native Schedule Definition can instead read an immutable Workspace revision and commit it to `published`, with a receipt in the same native commit. Workspace `ifHead` / `ifHeads` protect publication and queue state; only a competing conflict with a committed receipt counts as success. The fixture persists the queue in Workspace history, restarts workerd, invokes the generated Cron concurrently/repeatedly, verifies exactly one published revision and retains the later draft digest. This is a feasibility prototype for phase 3, not a production scheduler implementation. |
| Console fields / actions                     | The pinned public Content/Console types support schema fields, Blob pickers, Markdown components and fixed built-in section views/action sets. They provide no arbitrary relation picker, translation operation or proofreading button slot. Keep standard Console where sufficient; add only missing controls as Liti Nuxt admin pages behind the same server boundary in phase 4. This is a feature gap, not a bug patch. No Console component is copied.                                                                                                                                                                                                   |
| Concurrent commit constraints                | Public Database contributions are discovered in Nuxt and official CLI generation. Native SQL enforces games.igdbId, games.slug and gameStats(game, periodKey), restricts FK deletion/missing targets and rolls back failed batches on libSQL and D1. Content publication uses native Workspace CAS, not a process-local mutex. Keep Content integrity within Workspace refs and record integrity within SQL; operations requiring cross-store atomicity remain unsupported and must be rejected or explicitly limited by Model in phase 3.                                                                                                                    |
